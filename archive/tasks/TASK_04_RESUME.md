# TASK_04_RESUME

## 目标
实现简历诊断模块最小闭环，优先打通上传、任务创建、异步入队、任务消费、状态流转、结果保存与查询链路；本轮允许使用模拟诊断结果替代真实大模型输出。

## 当前背景
认证模块和额度模块已完成。
当前尚未配置真实大模型 API Key，因此本轮以“业务链路先跑通”为优先目标。

## 本轮范围
仅允许实现以下内容：
1. PDF 简历上传接口
2. 创建简历诊断任务记录
3. RabbitMQ 入队
4. 消费者监听任务
5. 任务状态流转：排队中 -> 解析分析中 -> 完成 / 失败
6. 使用模拟诊断结果生成器（stub/mock）产生结构化 JSON 结果
7. 结果保存与失败信息保存
8. 简历诊断任务状态查询接口
9. 简历诊断历史记录查询接口
10. 所有新增代码必须添加必要中文注释
11. 如果本轮新增或修改了前端需要访问的 HTTP 接口，必须同步生成接口文档
