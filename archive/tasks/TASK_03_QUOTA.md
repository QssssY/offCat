# TASK_03_QUOTA

## 目标
实现额度模块最小闭环，为简历诊断和模拟面试提供统一的次数校验与扣减能力。

## 当前背景
认证模块已完成，当前项目已支持用户注册、登录、JWT 和获取当前用户。
现在需要补齐用户额度能力，为后续业务模块提供前置校验。

## 本轮范围
仅允许实现以下内容：
1. 普通用户免费面试次数校验
2. 普通用户免费简历诊断次数校验
3. 会员用户每日面试次数校验
4. 会员用户每日简历诊断次数校验
5. 跨天自动刷新 daily_interview_used 和 daily_resume_used
6. 调用成功后的次数扣减逻辑
7. 所有新增代码必须添加必要中文注释
8. 如果本轮新增或修改了前端需要访问的 HTTP 接口，必须同步生成接口文档
