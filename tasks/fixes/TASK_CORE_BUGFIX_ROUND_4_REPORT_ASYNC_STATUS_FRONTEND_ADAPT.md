# TASK_CORE_BUGFIX_ROUND_4_REPORT_ASYNC_STATUS_FRONTEND_ADAPT

## 1. 任务目标
- 修复报告页和会话页对后端异步报告状态的适配问题
- 明确区分：会话进行中、会话已结束+报告生成中、报告已生成

## 2. 问题根因定位
- **根因 1**：前端仍沿用旧同步完成逻辑，没有区分"会话已结束"和"报告已生成"
- **根因 2**：会话结束后立即显示"查看报告"，但报告可能还在异步生成中
- **根因 3**：报告页缺少明确的"报告生成中"状态展示，用户看到空白会困惑

## 3. 修复实现

### 修复 1：InterviewReportView.vue
- 新增 `isReportGenerating` 计算属性：会话已结束 && 报告未生成 && 轮询进行中
- 新增 "报告生成中" 状态 UI：动画进度条 + 动态描述文案
- 修复目的：解决"会话已结束但报告仍在生成"的过渡态显示问题

### 修复 2：InterviewSessionView.vue
- `confirmEndInterview()` 结束后显示"评价报告正在生成，请稍后在报告页查看"
- 修复目的：结束会话后不立即引导看报告，提示报告会异步生成

### 修复 3：InterviewHistoryView.vue
- 新增 `reportStatus` 字段支持（待后端配合）
- 区分"已结束但报告未生成"和"已结束且报告已生成"

## 4. 影响范围
- 前端页面：
  - InterviewSessionView.vue
  - InterviewReportView.vue
  - InterviewHistoryView.vue

## 5. 验证要求
- 前端构建：`npm.cmd run build`

## 7. 验证场景说明

### 场景 1：结束会话后
- 页面显示"面试已结束，报告生成中..."
- 提示"评价报告正在生成，请稍后在报告页查看"

### 场景 2：报告生成中访问报告页
- 显示"报告生成中"状态卡片
- 动画进度条 + "请稍候，自动刷新中..."
- 有"立即刷新"和"查看会话"按钮

### 场景 3：报告生成完成
- 页面自动刷新显示完整报告内容

### 场景 4：历史页状态
- 已结束+报告未生成：显示"进行中"或"报告生成中"状态（warning）
- 已结束+报告已完成：显示"已结束"状态（success）
