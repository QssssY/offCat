# 模拟面试报告尾部未答追问评分口径修复

## 背景

最新 `debug.txt` 中，模拟面试技术链路已经正常完成，但报告把结束前最后一条面试官追问作为未回答题目并给出 0 分。这种情况通常发生在用户点击结束面试前，AI 刚生成了下一条追问，而候选人没有继续回答。

## 问题原因

报告 prompt 虽然已经补充有效问答轮次，但原始对话明细仍包含尾部未回答的面试官消息。模型在生成 `questionPerformance` 或 `roundReviews` 时可能把这条尾部追问当成独立题目，从而产生“候选人未回答/0 分”的不合理扣分。

## 实现内容

- `InterviewAiServiceImpl` 在报告原始对话明细中只保留到最后一个候选人回答。
- 尾部未回答的面试官追问仍作为上一轮“后续反馈或追问”上下文保留，帮助报告指出后续可练习方向。
- prompt 明确要求：没有候选人回答的尾部面试官消息不得作为独立 `questionPerformance/roundReviews` 条目，也不得因此给 0 分。

## 验证

- `mvn.cmd test "-Dtest=InterviewAiServiceImplTest"` 通过，39 个用例全绿。

## 边界

- 本轮只修复报告生成提示和原始对话明细口径，不修改聊天记录存储、会话结束逻辑或前端展示结构。
- 如果某条面试官追问后确实存在候选人回答，仍会作为有效问答轮次参与评分。
