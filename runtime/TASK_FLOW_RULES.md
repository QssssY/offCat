# 任务执行闭环规则

## 1. 适用范围
本规则适用于当前项目所有 TASK 任务的执行、收尾、归档和状态更新。

## 2. 每次执行 TASK 时的输出顺序
每次执行任务时，必须按以下顺序输出：
1. 本轮目标
2. 影响文件
3. 完整代码或文档
4. 接口文档（如有 Web 接口）
5. 自检结果
6. 任务完成后的状态更新建议
7. 任务归档建议
8. 蓝图进度对照报告

## 3. 任务完成后的强制动作
如果本轮任务完成并通过验收，必须同步执行以下事项：

### 3.1 更新 STATE.md
必须更新以下内容：
- 当前阶段
- 已完成任务清单
- 当前目标
- 下一步任务
- 当前规则提醒

### 3.2 归档已完成任务
如果本轮任务已完成：
- 将当前任务文件从 `tasks/` 移动到 `archive/tasks/`
- `tasks/` 中仅保留当前正在做的任务和下一个任务

### 3.3 输出进度报告
必须根据 `runtime/PROJECT_BLUEPRINT_MIN.md` 输出：
- 已完成步骤
- 当前所在步骤
- 剩余步骤
- 距离完成还差多少阶段

## 4. 蓝图进度报告格式
每次任务完成后，必须输出以下格式：

### 当前完成清单
- 已完成：TASK_01_BOOTSTRAP
- 已完成：TASK_02_AUTH
- 已完成：TASK_02A_AUTH_DOCS

### 当前所在阶段
- 当前阶段：TASK_03_QUOTA

### 蓝图剩余步骤
- TASK_04_RESUME
- TASK_05_INTERVIEW
- 历史记录相关接口补全
- 管理端基础能力接口（如规划保留）

### 当前完成度
- 已完成 X / Y 个阶段
- 当前进度约为 XX%

## 5. 注意事项
1. 不允许在未完成验收前归档任务

2. 不允许跳过 STATE.md 更新

3. 不允许省略蓝图差距报告

4. 如果当前环境无法直接移动文件，必须显式输出“请手动将任务文件移动到 archive/tasks/”

5. ## 返回体调用一致性检查
   每次任务完成后，必须检查本轮所有 Controller 中 `Result.success(...)` 和 `Result.error(...)` 的调用是否与当前 `Result` 工具类的方法签名一致。

   重点检查：
   - 参数个数是否一致
   - 参数顺序是否一致
   - 参数类型是否一致

   不允许在未通过该检查前结束本轮任务。
