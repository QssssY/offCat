# 后端项目压缩蓝图

## 1. 项目目标
从零实现“智能模拟面试与简历诊断系统”后端，服务于求职者用户与管理员，支持认证鉴权、用户额度控制、简历诊断异步处理、模拟面试流式会话、历史记录查询与基础后台管理能力。

## 2. 当前范围
当前只开发后端，不包含任何前端内容。

## 3. 固定技术栈
- JDK 21
- Spring Boot 3.x
- MyBatis-Plus
- Spring AI
- MySQL 8.0+
- Redis 6.0+
- RabbitMQ
- Maven

## 4. 后端核心模块
1. 基础工程骨架
2. 认证模块
3. 额度模块
4. 简历诊断模块
5. 模拟面试模块
6. 历史记录相关接口
7. 管理端基础能力接口

## 5. 核心业务链路

### 5.1 认证链路
用户注册 -> 创建用户 -> 初始化额度记录 -> 用户登录 -> 签发 JWT -> 获取当前用户信息

### 5.2 简历诊断链路
用户上传 PDF -> 创建诊断任务 -> RabbitMQ 入队 -> 消费任务 -> 文本解析 -> 读取 Prompt -> 调用 AI -> 保存诊断结果 -> 用户查询任务状态与历史

### 5.3 模拟面试链路
用户选择岗位与难度 -> 创建面试会话 -> 初始化 Redis 上下文 -> 读取 Prompt -> 调用 AI -> SSE 流式问答 -> 保存聊天记录 -> 结束会话 -> 生成综合评分与评价报告

## 6. 模块开发顺序
必须按以下顺序推进：
1. TASK_01_BOOTSTRAP
2. TASK_02_AUTH
3. TASK_03_QUOTA
4. TASK_04_RESUME
5. TASK_05_INTERVIEW

## 7. 当前数据库范围
当前核心表：
- sys_user
- user_quota
- sys_prompt
- resume_diagnosis_task
- interview_session
- interview_chat_log

## 8. 当前不做的内容
- 不开发前端
- 不接支付系统
- 不接短信平台
- 不做第三方登录
- 不做复杂微服务拆分
- 不做与后端核心链路无关的扩展功能

## 9. 成功标准
后端应做到：
- 项目可启动
- 接口可调用
- 数据可落库
- 简历诊断任务可异步流转
- 模拟面试支持流式交互
- 核心模块具备自测条件

仅在以下情况读取：

- 切换新模块
