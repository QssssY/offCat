# UI 风格约束指南（去 AI 味）

## 1. 风格定位

本项目 UI 风格定位为：

**专业 / 克制 / 工具型 / 信息优先**

这是一个真实业务系统，不是营销官网，也不是设计展示页。

核心目标：
- 信息清晰
- 操作高效
- 风格稳定
- 不追求视觉噱头

## 2. 允许的整体风格特征

✅ 允许：
- 中性色为主（白 / 灰 / 深灰）
- 单一主色 + 极少量强调色
- 清晰的层级和对齐
- 明确的信息区块划分
- 偏“后台 / 工具系统”的审美

🚫 禁止：
- 大面积渐变背景
- 玻璃拟态（Glassmorphism）
- 发光按钮、炫光描边
- Hero Banner 式大标题区
- 插画驱动页面
- 过多圆角和阴影堆叠

## 3. 色彩使用规则

- 主色只用于：
  - 关键操作按钮
  - 当前激活状态
  - 核心高亮信息
- 不允许多个页面随意更换主色
- 禁止为“好看”引入第二、第三主色
- 背景色以白色或极浅灰为主

## 4. 卡片与阴影规则

- 不允许“所有内容都包卡片”
- 卡片只用于：
  - 信息分组确实需要边界时
  - 模块之间逻辑独立时
- 阴影：
  - 默认不用
  - 如果用，必须非常轻
- 禁止层层嵌套卡片

## 5. 圆角与间距

- 圆角保持克制（小圆角即可）
- 不允许按钮、卡片、弹窗各用一套圆角
- 间距遵循统一节奏，不做“视觉拉伸”

## 6. 文案风格（重要）

✅ 使用：
- 具体、业务导向的描述
- 操作型文案（新增简历、创建面试）

🚫 禁止：
- “高效管理”
- “让一切更简单”
- “探索更多可能”
- “立即开始你的旅程”

## 7. 判断标准

如果一个页面：
- 看起来像产品宣传页
- 第一眼不像“业务系统”
- 更像 UI 展示模板

👉 那就不符合本项目 UI 风格。
