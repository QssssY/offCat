# 组件与交互一致性规范

## 1. 按钮规范

按钮分级必须清晰：
- 主操作：实色
- 次操作：描边或弱色
- 危险操作：红色，必须确认

禁止：
- 一个页面出现三种主按钮
- 所有按钮都用强调色

## 2. 表单组件规范

- 输入框高度统一
- 校验提示位置统一
- 错误信息明确，不用模糊提示
- 占位符只做示例，不当说明文案

## 3. 表格规范

- 行高统一
- 列名使用业务术语
- 操作列不超过 3 个直接操作
- 危险操作需二次确认

## 4. 弹窗规范

- 弹窗宽度分级（小 / 中 / 大）
- 标题明确说明动作
- 底部按钮顺序固定

## 5. 状态反馈

- 成功、失败、警告提示风格统一
- 不滥用 Toast
- 长操作必须有 loading 状态

## 6. 图标使用

- 图标只做辅助，不抢视觉
- 不为“好看”乱加图标
- 同类操作使用同一图标语义

## 7. 组件复用原则

- 同类业务组件必须复用
- 不允许页面私自复制组件代码
- 公共组件必须可配置，而不是硬编码

## 8. 判断标准

如果用户在多个页面中：
- 不需要重新学习操作方式
- 不会因为样式变化而犹豫

👉 说明组件规范是成功的。
