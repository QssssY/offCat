# TASK_17B_ADMIN_JOB_ROLE_TAG_UX_FIX

## 1. 当前任务所属模块
- 管理端前端模块
- 子模块：岗位配置标签体验修复

## 2. 问题根因分析
1. 旧版展示标签候选过少，覆盖不了真实岗位场景。  
2. 标签样式使用自由文本输入，不可控且容易写出无效值。  
3. 缺少可视化样式示例，配置人员无法判断样式差异。  
4. 弹窗没有完整用户端展示预览，难以确认最终效果。

## 3. 本轮 task 拆分
1. 扩充展示标签候选库，保留“可创建+多选”能力。  
2. 将标签样式从自由输入改为预设模板选择。  
3. 为每个样式模板提供可视化示例。  
4. 新增用户端展示预览区（岗位名称+标签+样式）。  
5. 保持后端接口契约不变，仅做前端映射与预览。  
6. 更新任务文档与阶段文档，构建验证后停止。

## 5. 关键实现说明
1. 展示标签  
- 保留 `allow-create + multiple`。  
- 默认标签库扩充到覆盖热门、招聘类型、级别、方向、职能等场景。  
- 选中标签实时预览，明确“已选内容”和“最终显示”。

2. 标签样式  
- 使用 `tagType` 作为“样式模板值”。  
- 前端维护模板映射：`模板值 -> 样式效果`。  
- 增加历史值兼容映射（如 `hot/common`），避免旧数据编辑异常。

3. 用户端展示预览  
- 在弹窗中新增预览区，展示岗位名称占位、标签列表和样式效果。  
- 未填写时提供合理占位提示，避免空白区域。
