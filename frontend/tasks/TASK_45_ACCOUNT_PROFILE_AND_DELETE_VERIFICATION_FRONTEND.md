# TASK 45 前端：注册时间展示与独立注销账号页

## 当前任务所属模块
- 首页身份卡
- 设置中心账号资料
- 设置中心账号注销

## 前端文件定位
- `frontend/app/src/views/DashboardView.vue`
- `frontend/app/src/views/settings/SettingsView.vue`
- `frontend/app/src/api/auth.js`
- `frontend/app/src/__tests__/views/SettingsView.test.js`

## 本轮修改文件清单
- `DashboardView.vue`：首页身份卡将会员到期时间展示改为注册时间。
- `SettingsView.vue`：账号资料区将会员到期时间改为注册时间；账号注销从账号安全底部移出，改为左侧导航独立页面。
- `auth.js`：新增当前登录账号安全问题接口封装，并更新注销请求参数说明。
- `SettingsView.test.js`：更新注册时间展示、注销页冷静期、安全问题加载和注销 payload 测试。

## 前端实现方案
- 首页身份卡展示 `userInfo.createTime`，异常或缺失时显示 `--`。
- 设置中心账号资料区展示 `userInfo.createTime`，不再把会员到期时间放在账号资料首页。
- 左侧导航新增“注销账号”。
- 注销账号页包含：
  - 明确高危警告区。
  - 三步风险说明：冷静期、密码确认、安全问题验证。
  - 当前密码、再次输入当前密码、安全问题答案表单。
  - 15 秒倒计时，倒计时结束前注销按钮禁用。
  - 最终确认弹窗，确认后才调用注销接口。
- 页面使用已登录接口读取当前账号真实安全问题，不复用忘记密码公共接口。

## 数据存储方案
- 前端不新增本地存储。
- 注册时间来自 `/api/auth/me` 返回的 `createTime`。
- 注销成功后沿用现有清 token、清用户态、跳转登录页逻辑。

## 当前功能验收说明
- 用户能在首页和设置中心账号资料看到注册时间。
- 设置中心账号安全页不再在底部塞入注销账号危险行。
- 注销账号作为独立导航项，具有明显高危提示和 15 秒冷静期。
- 注销请求必须带当前密码、确认密码和安全问题答案。

## 验证结果
- `npm.cmd test` 通过，18 个测试文件、86 个测试用例通过。
- `npm.cmd run build` 通过。

## 停止说明
- 本轮只处理注册时间展示和账号注销交互/验证增强，不继续扩展账号数据导出、账号恢复、管理端注销或其他设置中心能力。
