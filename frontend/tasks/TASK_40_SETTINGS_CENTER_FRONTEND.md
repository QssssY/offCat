- 编译结果：本轮不涉及后端编译。

## 5. 前端实现方案
- 新增 `/settings` 页面，包含账号资料、账号安全、外观偏好、通知偏好、新手引导、会员与额度六个分区
- 账号资料不展示普通用户不需要理解的用户 ID 和套餐代码；订阅套餐通过会员套餐列表匹配套餐名称，匹配失败时不暴露内部编码
- 账号资料补充“会员到期时间”，会员用户展示年月日，非会员展示“未开通会员”，避免三项信息卡视觉不均衡
- 昵称修改恢复到头像下拉菜单，保存成功后刷新 `userStore.fetchUserInfo()`；设置中心仅展示昵称，不提供修改入口；弹窗补齐头像、当前昵称和移动端全宽按钮适配，弹窗宽度使用 `min(440px, calc(100vw - 24px))`
- 账号安全复用 `updatePassword` 和 `updateSecurityQuestion`
- 账号安全改为类似首页导航的按钮式切换，切换时清理未展示表单状态；表单内部不再重复显示“修改密码 / 修改安全问题”标题
- 外观偏好复用 `themeStore`，支持跟随系统、亮色、暗色；页面改为卡片式选择，并提示偏好已保存到当前浏览器
- 通知偏好通过 `localStorage` 保存，仅影响当前浏览器
- 顶部通知铃铛在关闭实时提醒时不建立 SSE 和轮询
- 通知中心读取本地默认筛选，支持默认只看未读和默认类型
- 新手引导复用 `OnboardingGuide`，只负责重新打开，不修改引导完成状态
- 头像下拉菜单保留“修改昵称”，移除“修改密码 / 修改安全问题”，安全类操作集中放在设置中心

## 12. 当前功能验收说明
- 用户可从头像菜单与移动端抽屉进入设置中心
- 用户可在设置中心管理密码、安全问题、主题、本机通知偏好与会员额度查看
- 账号资料不再展示用户 ID 和套餐代码，订阅套餐只展示用户可理解的套餐名称或兜底文案
- 账号资料补充会员到期时间，区分会员和非会员状态
- 用户可从头像下拉菜单打开昵称弹窗并保存
- 昵称弹窗在桌面和窄屏下保持可读，窄屏按钮纵向排列
- 账号安全使用导航式切换，只展示当前切换项对应的一个表单，避免两个安全表单同时铺开
- 外观偏好以卡片方式展示，并通过 `themeStore` 本地持久化，下次打开页面会恢复上次选择
- 头像下拉菜单不再重复展示修改密码、修改安全问题
- 关闭顶部实时通知提醒后，顶部不再显示通知铃铛，也不保持实时连接
- 打开通知中心时可自动带入本机保存的默认筛选条件
