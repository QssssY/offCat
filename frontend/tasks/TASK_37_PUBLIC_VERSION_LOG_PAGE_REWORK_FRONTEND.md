## 4. 本轮修改文件清单
- 重构公开版本日志页 `/version-logs` 的页面结构、视觉层级和响应式布局。
- 公开页状态与辅助展示使用 Naive UI 的按钮、标签、骨架屏、空状态和错误状态组件；分页保留 Element Plus，和站内其他页面保持一致。
- 新增公开版本日志页组件测试，覆盖正常数据、空数据、请求失败重试、长文本展开收起和分页参数。

## 5. 前端实现方案
- 公开版本日志页继续通过 `getPublicVersionLogsPage({ page, size })` 查询已发布版本日志，不新增筛选条件。
- 页面顶部使用紧凑标题区，保留返回首页入口。
- 主体改为稳定单列日志卡片，弱化装饰性序号，提升标题、正文和日期对比度。
- 长正文默认折叠为 4 行，用户按需展开，避免单条日志把页面高度和卡片结构撑坏。
- 首次加载显示骨架屏；接口失败显示错误说明和重新加载按钮；无数据时显示空状态说明。
- 默认每页 5 条；分页保留 Element Plus `el-pagination`，页码和每页数量变化后重新调用现有分页接口。
