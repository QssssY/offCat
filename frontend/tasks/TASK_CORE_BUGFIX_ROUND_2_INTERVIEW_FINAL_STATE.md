# TASK_CORE_BUGFIX_ROUND_2_INTERVIEW_FINAL_STATE（前端子任务）

## 任务范围
- 会话结束后强制只读态，禁止继续输入、发送、结束。
- 报告生成中的状态文案统一为“已结束，报告生成中”。
- 历史页重新进入已结束会话时，保持只读行为一致。

## 实施项
- `InterviewSessionView.vue`
  - 结束按钮在终态下禁用（不再可点击重复结束）。
  - 输入框与发送按钮在终态下禁用，且展示只读提示文案。
  - 发送方法增加只读态前置拦截，避免前端误触发请求。
  - 会话详情刷新到终态后自动清空输入并关闭结束弹窗。
  - 状态栏与底部提示统一显示“已结束，报告生成中”。
- `InterviewHistoryView.vue`
  - 已结束且报告未就绪时，状态标签统一显示“已结束，报告生成中”。
