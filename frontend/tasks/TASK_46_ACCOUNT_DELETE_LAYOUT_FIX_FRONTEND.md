- 解除注销表单继承的通用 `settings-form` 最大宽度限制，让输入框在右侧表单列内完整铺开。

- 保留原有冷静期、安全问题折叠、密码二次确认、最终确认弹窗和接口 payload，不改变业务逻辑。
