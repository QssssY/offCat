# TASK_08: 简历诊断主链路联调验收与体验收尾

## 1. 验收目标

验证简历诊断完整主链路从前端到后端的端到端可用性，确保核心用户旅程无阻断，体验符合 MVP 标准。

### 核心目标
- [ ] 首页 → 上传 → 诊断 → 结果 → 历史 全链路贯通
- [ ] 登录态校验在各环节正常生效
- [ ] 错误处理和边界情况有合理反馈
- [ ] 左侧导航激活态与当前路由保持一致

### 体验目标
- [ ] 上传等待、诊断轮询过程有明确 loading 反馈
- [ ] 结果页结构化展示清晰可读
- [ ] 历史记录列表可正常浏览并支持点击查看详情
- [ ] 页面切换流畅，无明显卡顿

---

## 2. 验收范围

### 2.1 包含范围

| 模块 | 页面/组件 | 功能点 |
|------|----------|--------|
| 首页 | HomeView.vue | 入口展示、导航跳转 |
| 侧边栏 | MainLayout.vue | 导航菜单、激活态、登录态展示 |
| 上传页 | UploadView.vue | 文件选择、上传 API 调用、loading 状态 |
| 结果页 | ResultView.vue | 任务轮询、结果展示、结构化渲染 |
| 历史记录 | HistoryView.vue | 列表查询、分页/无限滚动、详情跳转 |
| 路由守卫 | router/index.js | 登录校验、跳转拦截 |

### 2.2 不包含范围
- 模拟面试模块（Interview）功能开发
- 后端 API 优化和性能调优
- 移动端适配优化
- 单元测试和 E2E 测试建设
