### TASK_10D_FE_INTERVIEW_REPORT_VIEW

**类型：前端 Task**

**目标：​**  
开发模拟面试结果“查看评价报告”界面与交互，支持用户从历史记录或会话详情中查看已结束面试的综合评分与评价报告。

**前提：​**
1. 面试历史分页已可用
2. 会话详情接口已可用
3. 后端详情返回包含：
   - `comprehensiveScore`
   - `evaluationReport`

**要求：​**
1. 在“已结束”面试记录中提供“查看报告”入口
2. 展示 `comprehensiveScore`
3. 展示 `evaluationReport`
4. 未结束面试不显示或禁用“查看报告”
5. `evaluationReport` 为空时显示空状态，不报错
6. 尽量复用现有页面结构，不做无关大改

**输出要求：​**
1. 修改文件清单
2. 页面入口位置说明
3. 关键展示代码
4. 空状态/未结束状态处理方式
