## 启动与运行时流程

ServerApplication.main() -> @MapperScan("com.airesume.server.mapper") -> SpringApplication.run() -> 自动装配 SecurityConfig（JwtAuthenticationFilter前置）-> 等待HTTP请求

简历诊断异步链路：ResumeDiagnosisController.uploadResume() -> ResumeDiagnosisProducer.send() -> RabbitMQ resume_diagnosis_queue -> ResumeDiagnosisConsumer.receive() -> MockDiagnosisResultGenerator（当前为Mock）

模拟面试流式链路：InterviewController.streamMessage() -> 新线程中调用 interviewAiService.generateReplyStream() -> ResponseBodyEmitter SSE推送

UserQuota - 额度实体（db/schema.sql:40）：user_id, total_interview_used, total_resume_used, interview_quota, resume_quota, daily_interview_used, daily_resume_used, last_refresh_date

ResumeDiagnosisTask - 诊断任务（db/schema.sql:191）：user_id, file_url, status(0待处理/1处理中/2完成/3失败), diagnosis_result(JSON), error_msg

SysPrompt - Prompt模板（db/schema.sql:108）：scenario_type(1面试/2简历), job_role_code, difficulty, prompt_content, is_active

SysAiEngineConfig - AI引擎配置（db/schema.sql:145）：engine_code, provider_type, business_type(interview/resume), model_name, base_url, api_key, is_active

SysJobRole - 岗位配置（db/schema.sql:128）：role_code, role_name, interview_tag, tag_type, is_active, sort

## 数据流与持久化

- **ORM层**：MyBatis-Plus 逻辑删除（is_deleted=1）全局配置于 application.yml:63-65
- **主数据**：MySQL，13个业务表 + 3个系统表
- **缓存**：Redis，JVM外缓存，用于JWT状态等
- **异步队列**：RabbitMQ，队列名 resume_diagnosis_queue（ResumeDiagnosisConstants）
- **文件存储**：本地文件URL，file_url字段存储路径
- **JSON字段**：诊断结果 diagnosis_result、评价报告 evaluation_report、分析结果 analysis_result 均为JSON

## 架构观察

1. **分层清晰**：Controller -> Service -> Mapper 三层，部分业务有 infrastructure/ 基础设施层和 mock/ Mock层
2. **明显耦合点**：InterviewAiService 接口有两个实现（MockInterviewAiServiceImpl / InterviewAiServiceImpl），通过 @ConditionalOnProperty 切换，但 InterviewController 直接注入接口，不感知具体实现
3. **可疑废弃模块**：InterviewController:209 标记 @Deprecated 的 /api/interview/history/all 未分页接口仍在服务中
4. **跨层依赖**：部分Controller直接注入Mapper（如 InterviewController:38 注入 InterviewChatLogMapper），违反分层原则
5. **DTO/VO混乱**：dto/vo/response混用，部分Response直接复用entity字段

## 后续AI需沿用的约定

**命名风格**：
- 类名：大驼峰（PascalCase），如 ResumeDiagnosisTaskService
- 方法名：小驼峰（camelCase），如 createTask, getHistoryByUserId
- 常量：全大写下划线，如 USER_ROLE_NORMAL, QUEUE_RESUME_DIAGNOSIS
- 包名：小写单数/复数混用，如 common/, service/impl/

**错误处理**：
- 抛出 BusinessException（自定义异常）而非 RuntimeException
- 全局异常统一由 GlobalExceptionHandler 处理
- 响应统一用 Result<T> 包装，成功 Result.success(data)，失败 Result.error(code, msg)

**日志规范**：
- 使用 Lombok @Slf4j 注入 log
- 方法入口打印 log.info，包含关键参数
- 异常打印 log.error 或 log.warn

**分页返回**：统一使用 PageResult<T>，包含 total, records, pageNum, pageSize
